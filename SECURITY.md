# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **tachyon**, please do not open a public issue.

Instead, please report it through one of the following channels:
1. **GitHub Security Advisories:** Use the [Private Vulnerability Reporting](https://github.com/xdearboy/tachyon/security/advisories/new) page on GitHub.
2. **Email:** Reach out privately to `xdearboy@users.noreply.github.com`.

### What to include in your report
* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue (PoC, curl command, or sample input).
* Affected versions and environment details (Linux kernel version, OpenSSL version).

### Response timeline
* **Initial response:** Within 48 hours.
* **Status update:** Within 7 days with an assessment and fix timeline.
* **Public disclosure:** Coordinated after a patched release is published.
